## Descripción

Programa en Java que simula las operaciones básicas de un cajero automático para una sola cuenta bancaria: control de acceso por PIN, consulta de saldo, depósitos, retiros normales y con comisión, y resumen de la sesión. Todo se ejecuta desde consola utilizando `Scanner`.

## Cómo ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase principal `CajeroAutomatico` (botón ▶ sobre el método `main`).
3. Seguir las instrucciones que aparecen en consola.
